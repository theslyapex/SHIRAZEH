# SHIRAZEH | رزومه‌ساز شیرازه

رزومه‌ساز فارسی با ۱۰ قالب، پیش‌نمایش زنده، عکس پروفایل، مهارت‌های درصدی، ذخیره محلی و endpoint سمت سرور برای قابلیت‌های هوش مصنوعی.

## امکانات
- رابط واکنش‌گرا، RTL و فارسی
- ۱۰ قالب بصری مستقل
- اطلاعات تماس، خلاصه حرفه‌ای، تجربه کاری، تحصیلات، مهارت‌ها، زبان‌ها، دوره‌ها، پروژه‌ها و لینک‌ها
- تصویر پروفایل و نوارهای سطح مهارت
- پیش‌نمایش زنده، تغییر رنگ و خروجی چاپ/PDF
- ذخیره خودکار اطلاعات متنی در مرورگر
- API سمت سرور برای بهبود خلاصه، بازنویسی تجربه، نامه پوششی و بررسی تناسب با آگهی
- کلید API از متغیر محیطی سرور خوانده می‌شود و در کد مرورگر قرار ندارد

## اجرا
نیازمند Node.js 18 یا جدیدتر است.

```bash
npm install
cp .env.example .env
```

در فایل `.env` روی سرور مقدار `OPENAI_API_KEY` را با کلید خودت تنظیم کن، سپس:

```bash
npm start
```

سایت روی `http://localhost:3000` اجرا می‌شود. مدل پیش‌فرض `gpt-4.1-mini` است و با متغیر `OPENAI_MODEL` قابل تغییر است. کلید API را هرگز داخل `index.html`، مخزن عمومی یا چت عمومی قرار نده.

## استقرار
برای endpoint هوش مصنوعی به میزبان Node.js نیاز است. GitHub Pages به‌تنهایی کد سرور را اجرا نمی‌کند. متغیرهای محیطی را در تنظیمات میزبان مستقرشده وارد کن.

## حریم خصوصی و وضعیت MVP
متن رزومه در نسخه اولیه در مرورگر ذخیره می‌شود. تصویر پروفایل در حافظه همان صفحه باقی می‌ماند و به localStorage اضافه نمی‌شود. اطلاعات فقط با کلیک روی ابزار AI به endpoint ارسال می‌شوند. پیش از استفاده عمومی، محدودسازی درخواست‌ها، سیاست حریم خصوصی، محافظت در برابر سوءاستفاده و بررسی امنیتی تکمیل شوند.
