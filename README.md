# SHIRAZEH | رزومه‌ساز شیرازه

رزومه‌ساز فارسی با ۱۰ قالب، پیش‌نمایش زنده، عکس پروفایل، مهارت‌های درصدی، ذخیره محلی، چک‌لیست رزومه و خروجی چاپ/PDF.

## امکانات
- رابط واکنش‌گرا، راست‌چین و فارسی
- ۱۰ قالب بصری مستقل
- اطلاعات تماس، خلاصه حرفه‌ای، تجربه کاری، تحصیلات، مهارت‌ها، زبان‌ها، دوره‌ها، پروژه‌ها و لینک‌ها
- تصویر پروفایل و نوارهای سطح مهارت
- پیش‌نمایش زنده، تغییر رنگ و خروجی چاپ/PDF
- ذخیره خودکار اطلاعات متنی در مرورگر
- چک‌لیست تعاملی برای بررسی رزومه پیش از ارسال

## اجرا
نیازمند Node.js 18 یا جدیدتر است.

```bash
npm install
npm start
```

سایت روی `http://localhost:3000` اجرا می‌شود. برای اجرای مستقیم می‌توان `index.html` را نیز در مرورگر باز کرد؛ بعضی قابلیت‌های مرورگر ممکن است به نحوه میزبانی وابسته باشند.

## استقرار
می‌توان فایل‌های سایت را روی میزبان استاتیک منتشر کرد. اگر از GitHub Pages استفاده می‌کنی، تنظیمات انتشار مخزن را بررسی کن.

## حریم خصوصی
متن رزومه در نسخه اولیه در مرورگر ذخیره می‌شود. اطلاعات رزومه به سرویس هوش مصنوعی یا endpoint خارجی ارسال نمی‌شود.
